# KiCad Pad Editor

iPad·iPhone의 Safari에서 KiCad 파일을 열어 보고, 고치고, 다시 저장하는 웹앱(PWA)입니다.
빌드 과정이 없는 정적 파일이라 GitHub Pages에 그대로 올라갑니다.

## 쓰는 법

1. iPad Safari에서 `…/kicad-editor/` 를 엽니다.
2. 공유 버튼 → **홈 화면에 추가**를 하면 전체 화면 앱처럼 열리고 오프라인에서도 동작합니다.
3. **열기**로 파일 앱(iCloud Drive 등)에 있는 KiCad 파일을 고릅니다.
4. 고친 뒤 **저장**(다운로드 폴더에 저장) 또는 **공유**(공유 시트 → “파일에 저장”)로 내보냅니다.

| 조작 | 동작 |
|---|---|
| 한 손가락 끌기 | 화면 이동 |
| 두 손가락 벌리기/오므리기 | 확대/축소 |
| 탭 | 선택 (같은 자리를 다시 탭하면 겹친 다른 항목으로 넘어감) |
| 선택한 항목 끌기 | 이동 (격자에 맞춰짐) |
| 선택한 배선의 끝점 끌기 | 끝점만 이동 |

## 지원 범위

여러 파일을 탭으로 함께 열 수 있고, 회로도 심볼과 PCB 풋프린트는 참조 번호로 서로 찾아갈 수 있습니다.

| 파일 | 할 수 있는 것 |
|---|---|
| `.kicad_sch` 회로도 | 심볼·라벨·텍스트·배선 이동, 회전, 삭제, 값/참조/풋프린트 수정, 배선·라벨·접점·미연결 표시·텍스트 추가, **연결 검사(ERC)** |
| `.kicad_pcb` 보드 | 레이어 켜기/끄기, 네트 강조, 풋프린트 이동·회전, **배선(패드↔패드 자동 붙기, 45° 꺾임)·비아 추가**, 트랙 끝점·폭·레이어 수정, **미연결선 표시와 DRC**, **3D 보기** |
| `.kicad_mod` 풋프린트 | 패드 이동·크기·모양·종류(SMD/스루홀)·드릴·번호 수정, 패드 추가, 선 그리기, 텍스트 수정 |
| `.kicad_sym` 심볼 라이브러리 | 보기 |

KiCad 6 이상의 S-expression 형식을 읽습니다. KiCad 5 이하(`.sch`, `.brd`)는 지원하지 않습니다.

### 검사 (DRC / ERC)

- **PCB**: 구리 간격·단락, 최소 배선 폭, 비아 지름/드릴/애뉼러 링, 보드 외곽 간격, 미연결을 확인합니다. 기준값은 검사 패널에서 바꿉니다(`.kicad_pro`의 규칙은 읽지 않습니다).
- 배선이나 비아를 추가하면 그 연결만 바로 검사해 결과를 알려 주고, 항목을 선택하면 그 항목의 DRC 상태와 가장 가까운 다른 네트까지의 간격을 보여 줍니다.
- **회로도**: 연결되지 않은 핀, 떠 있는 배선 끝, 배선에 붙지 않은 라벨, 참조 번호 중복을 확인합니다.
- KiCad의 DRC/ERC를 대체하지는 않습니다. 영역(zone) 채움 간격, 코트야드, 핀 종류 충돌 등은 검사하지 않습니다.

### 3D 보기

보드 외곽을 두께만큼 세우고 구리·실크를 입힌 뒤, 부품은 풋프린트 크기로 추정한 상자/원통으로 올립니다. STEP/WRL 3D 모델은 불러오지 않습니다.

하지 않는 것: 새 심볼/풋프린트 배치, 자동 배선, 영역(zone) 다시 채우기.
부품을 옮겨도 연결된 배선은 따라오지 않습니다. 저장한 뒤 KiCad에서 열어 영역을 다시 채우고(B) DRC를 돌리세요.

## 저장 방식

파일 전체를 다시 써내지 않고, **고친 토큰만 원본 텍스트에서 바꿔 끼웁니다.**
그래서 아무것도 고치지 않으면 저장 결과가 원본과 바이트 단위로 같고, 고친 경우에도 git diff가 고친 줄에만 생깁니다.
파일은 기기 밖으로 나가지 않습니다. 작업 중인 내용은 브라우저 저장소(IndexedDB)에 임시 보관되어 새로 고침 뒤 “이어서 편집”으로 되살릴 수 있습니다.

## 구조

```
index.html, style.css      화면
js/sexpr.js                S-expression 파서 / 원본 보존 직렬화
js/draw.js                 도형 그리기, 거리 계산
js/pcb.js                  PCB · 풋프린트 문서
js/sch.js                  회로도 · 심볼 라이브러리 문서
js/conn.js                 PCB 연결 계산, 미연결선, DRC
js/erc.js                  회로도 연결 검사
js/view3d.js               3D 보기 (three.js)
js/app.js                  터치 입력, 탭, 열기/저장, 실행 취소, 패널
vendor/                    three.js r170 (MIT)
sw.js, manifest.webmanifest  오프라인 · 홈 화면 설치
samples/                   예제 회로도 / PCB (KiCad 7 형식)
```
