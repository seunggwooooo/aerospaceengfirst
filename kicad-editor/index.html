KiCad Pad Editor

iPad·iPhone에서 KiCad 파일을 열어 보고, 고치고, 다시 저장합니다.

  • 지원 파일 .kicad_sch 회로도 · .kicad_pcb 보드 · .kicad_mod 풋프린트 편집, .kicad_sym 보기 (KiCad 6 이상). 여러 파일을 탭으로 함께 엽니다. .kicad_pro를 열면 설계 규칙을 불러옵니다.
  • 기능 부품 추가·복제 · 회로도 배선 · PCB 배선과 비아 · 연결/설계 규칙 검사(ERC·DRC) · BOM 내보내기 · 3D 보기 · 풋프린트 패드 편집
  • 조작 한 손가락 끌기 = 화면 이동 · 두 손가락 = 확대/축소 · 탭 = 선택 · 선택한 것을 끌기 = 이동
  • 저장 파일은 서버로 보내지 않고 이 기기 안에서만 처리합니다. 수정한 부분만 바꿔 써서 원본 형식을 그대로 유지합니다.
  • 홈 화면에 추가 Safari 공유 버튼 → “홈 화면에 추가”를 하면 앱처럼 전체 화면으로 열리고 오프라인에서도 동작합니다.
한 손가락: 회전 · 두 손가락: 이동/확대 · 부품은 실제 3D 모델이 아닌 크기 기준 근사 형상입니다
