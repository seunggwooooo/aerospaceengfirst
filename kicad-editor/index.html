KiCad Pad Editor

iPad·iPhone에서 KiCad 파일을 열어 보고, 고치고, 다시 저장합니다.

  • 지원 파일 .kicad_sch .kicad_pcb 편집 · .kicad_mod .kicad_sym 보기 (KiCad 6 이상)
  • 조작 한 손가락 끌기 = 화면 이동 · 두 손가락 = 확대/축소 · 탭 = 선택 · 선택한 것을 끌기 = 이동
  • 저장 파일은 서버로 보내지 않고 이 기기 안에서만 처리합니다. 수정한 부분만 바꿔 써서 원본 형식을 그대로 유지합니다.
  • 홈 화면에 추가 Safari 공유 버튼 → “홈 화면에 추가”를 하면 앱처럼 전체 화면으로 열리고 오프라인에서도 동작합니다.
